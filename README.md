#Explicación/descripción 
Tenenmosuna struct de clientes en la cual se almacenaran los siguientesdatos: 
1. n_cuenta:Este es un dato de tipo entedero.
2. nombre: Es un tipo de dato de carácter el cual tiene 40 caracteres para almacenar el nombre del usuario.
3. apellido:Es un tipo de dato de carácter el cual tiene 40 caracteres para almacenar el apellido del usuario.
4. nip:Es un tipo de dato entero en el cual se almacena el nip del usuario.
5. saldo: Es un tipo de dato flotante, se almacena la cantidad de dinero que tiene enl usuario en su cuenta.
6. bloqueada: Es un tipo de dato entero, se almacena los datos y si en el bloqueo es un -2, se bloquea la cuenta.
7. intentos: Es un tipo de datos entero, se almacena los intentos que usuario hace para acceder a su cuenta, con base a este dato y al dato bloqueo se valida el nip.
8. movimientos: Esun tipode dato entero, tiene un capacidad de 10 movimientos. Con esta se veran reflejados los movimientos realizados.
